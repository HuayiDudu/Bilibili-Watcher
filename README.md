# B站视频监控工具

按固定周期采样 B 站视频的公开数据，实时看趋势，停止时产出 JSON 报告。

## 运行

Windows 下双击 `start.bat`，或：

```
python app.py
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | 8765 | 被占用时自动向后顺延 |
| `--no-browser` | 关 | 不自动打开浏览器 |

要求 Python 3.12+，无第三方依赖。

## 功能

- **多监控**：最多同时跟踪 5 个视频，各自独立采样，切换只切换查看
- **指标**：播放量、弹幕、评论、点赞、投币、收藏、分享、同时在看
- **报告**：停止监控即生成，可下载、导入、导出、删除，内容重复的自动跳过
- **设置**：自动保存目录、报告自动导入目录、整点采样

## 测试

```
test.bat
```

后端用标准库 `unittest`，前端图表用 `node:test`；未安装 Node 时只跑后端。

## 目录

| 路径 | 内容 |
|---|---|
| `app.py` | 启动入口，只做装配 |
| `bilimon/` | 后端：采集、会话、报告、配置、HTTP |
| `web/` | 前端：页面、图表、文件选择器 |
| `tests/` | 后端测试 |
| `docs/` | 架构说明与图表 |

## 运行期文件

| 文件 | 内容 |
|---|---|
| `reports/` | 报告仓库，首次写入时自动创建 |
| `config.json` | 本机设置 |
| `cooldown.json` | 限流冷却，重启后继续生效 |

三者均不纳入版本库。

## 已知边界

- 监控与样本只存在内存，重启即丢失；报告停止时才落盘
- 接口请求受 B 站限流约束，采样周期下限 5 秒
- 只接受本机页面的请求，非回环来源返回 403
